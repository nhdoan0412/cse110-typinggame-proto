# User Stories

- As a beginner, I want to see the concept behind each snippet so that I connect syntax to purpose.
- As a player, I want immediate typo feedback so that I can correct mistakes before habits form.
- As a mobile user, I want touch controls for movement so that the game works without a keyboard.
- As a returning player, I want my best run saved so that replay has a reward.
- As a maintainer, I want syntax prompts grouped into packs so that new topics can be added incrementally.
