# 1. Vanilla Static App

## Status

Accepted

## Context

The course constraints prefer standards-based HTML, CSS, and vanilla JavaScript. Deployment must work on GitHub Pages or Cloudflare Pages, and dependencies need TA approval.

## Decision

Build the prototype as a static vanilla JavaScript app with no runtime dependencies.

## Consequences

The app is easy to deploy and review. More complex game systems must be implemented carefully because there is no framework managing state or rendering.
